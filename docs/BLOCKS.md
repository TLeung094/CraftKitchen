# 自訂方塊

CraftKitchen 不註冊新方塊，而是用「原版方塊 + 潛行右鍵事件監聽」偽裝成烹飪設備。原版模式零依賴；CraftEngine 模式可改用 CE 真方塊（規劃中）。

## 烹飪設備

| 設備 | 原版方塊 | 步驟 | 觸發 |
|---|---|---|---|
| 砧板 | 木製壓力板 / 切石機 | `cut` | 潛行右鍵 |
| 醃漬台 | 釀造台 | `marinate` | 潛行右鍵 |
| 爐灶 | 營火 / 靈魂營火 | `cook` | 潛行右鍵（需點燃） |
| 調味台 | 工作台 | `season` | 潛行右鍵 |

> 為何潛行？工作台／釀造台右鍵會開啟原版介面，潛行可繞過介面直接觸發烹飪邏輯。

## 爐灶點燃 / 澆滅

爐灶（營火）有「點燃狀態」。`cook` 步驟必須在已點燃的爐灶上才能進行。

| 操作 | 條件 | 結果 |
|---|---|---|
| 潛行右鍵營火 + **打火石** | — | 點燃爐灶（訊息「爐灶已點燃」） |
| 潛行右鍵營火 + **水桶** | 已點燃 | 澆滅爐灶（訊息「爐灶已熄滅」） |
| 潛行右鍵營火（其他） | 已點燃 | 進行 `cook` 步驟 |
| 潛行右鍵營火（其他） | 未點燃 | 提示「爐灶尚未點燃」 |

狀態以方塊位置（世界+座標）為索引，由 `StoveState` 追蹤。

> ⚠️ 狀態存於**記憶體**，伺服器重啟後所有爐灶回未點燃。這是 v1 行為，未來可持久化至 SQLite。

## 方塊保護

目前不阻止玩家破壞這些原版方塊（它們本就是原版方塊）。若需保護，建議搭配第三方保護插件（如 WorldGuard）或在 `BlockBreakEvent` 自行擴充。
