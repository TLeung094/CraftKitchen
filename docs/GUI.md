# 廚房 GUI

CraftKitchen 提供遊戲內 GUI 介面，讓玩家以視覺化方式瀏覽食譜、查看等級與烹飪指南。

## 開啟方式

| 指令 | 說明 |
|------|------|
| `/kitchen` | 直接開啟主目錄（玩家限定） |
| `/kitchen menu` | 同上 |
| `/ck` | `/kitchen` 的別名，`/ck menu` 可用 |

> 需要 `craftkitchen.use` 權限（預設所有人可用）。

## 五個視窗

### 主目錄
27 格介面，含三個入口按鈕：
- **食譜大全**（知識之書）→ 食譜清單
- **料理等級**（玩家頭顱）→ 等級資訊
- **烹飪指南**（書本）→ 步驟與品質說明
- 若有進行中食譜，額外顯示 **時鐘** 按鈕，點擊以聊天訊息列出進度

### 食譜清單（分頁）
54 格介面，每頁最多 45 道食譜。每道食譜以其成品圖示顯示，滑鼠懸停可見：
- 步驟順序（cut → marinate → cook）
- 所需食材
- 效果摘要

點擊進入食譜詳情。底列有 **上一頁／返回目錄／下一頁** 導航。

### 食譜詳情
27 格介面：
- 中央：成品預覽（含品質與效果 lore）
- 中排：四個步驟指示器（cut/marinate/cook/season），**綠色**=本食譜需要，**暗灰**=不需要，並標示對應方塊
- 底排：食材圖示
- 左下：返回清單（回到原頁碼）

### 烹飪指南
27 格介面：
- 步驟→方塊對應表（切石機/釀造台/營火/工作台）
- 品質分級說明（失敗→傳說，倍率 0.5x~2.0x）
- 爐灶點燃／澆滅方式

### 料理等級
27 格介面：
- 玩家頭顱：等級、稱號、經驗、距下一級尚需多少
- 經驗獲取說明（品質越高經驗越多）

## 設計原則

- **純瀏覽介面**：GUI 內所有點擊與拖曳一律取消，玩家無法從介面取走物品——料理仍須透過「潛行右鍵方塊觸發烹飪」取得。
- **InventoryHolder 標記**：以 `GuiHolder` 辨識自身 GUI，不干擾玩家背包或第三方介面。
- **分頁純邏輯**：`GuiLayout` 為無狀態工具類，與 inventory 渲染解耦，可單元測試。
- **指令相容**：原有 `/kitchen recipe`、`/kitchen level` 等聊天指令保留不變。
