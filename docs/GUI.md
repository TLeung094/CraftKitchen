# 森羅物語 · 廚房 GUI

> 「循四時之序，烹森羅真味；萬物有靈，皆可成饌。」

CraftKitchen 提供遊戲內 GUI 介面，讓玩家以視覺化方式瀏覽食譜、查看等級與烹飪指南。GUI 以「森羅物語」童話森林廚房為主題：苔綠面板、橡葉邊飾、古書架導航、金葉書頁。

## 開啟方式

| 指令 | 說明 |
|------|------|
| `/kitchen` | 直接開啟**森羅之門**（主目錄，玩家限定） |
| `/kitchen menu` | 同上 |
| `/kitchen`（無參數） | 同上 |
| `/ck` | `/kitchen` 的別名，`/ck menu` 可用 |

> 需要 `craftkitchen.use` 權限（預設所有人可用）。

## 五個視窗

### 森羅之門（主目錄）
27 格介面，含三個入口按鈕：
- **森羅食譜**（知識之書）→ 食譜清單（書脊詩句：「萬物有靈，皆可成饌」）
- **森羅廚階**（玩家頭顱）→ 等級資訊
- **森羅烹飪指南**（書與筆）→ 步驟與品質說明（書脊詩句：「循四時之序，烹森羅真味」）
- 若有進行中食譜，額外顯示 **時鐘** 按鈕（黃色），點擊以聊天訊息列出進度

邊飾：四角橡葉作為框架。

### 森羅食譜（分頁）
54 格介面，每頁最多 45 道食譜。每道食譜以其成品圖示顯示，滑鼠懸停可見：
- 書脊詩句（如「林間漫步」）
- 步驟順序（伐枝 → 浸露 → 燒柴 → 點芳）
- 所需食材
- 效果摘要
- 提示：「翻開這頁，覽森羅詳情」

點擊進入食譜詳情。底列有 **前章／歸森羅之門／後章** 導航（古書架背景）。

### 食譜詳情
27 格介面：
- 中央：成品預覽（含**森羅之味**與效果 lore，黃金名字）
- 中排：四個步驟指示器（伐枝/浸露/燒柴/點芳），**綠色✦**=本食譜需要，**暗灰✧**=不需要，並標示對應方塊（森林砧板/森林醃製台/森羅爐灶/森羅調味桌）
- 底排：食材圖示
- 左下：**歸去**（綠色箭頭）返回清單

邊飾：四角橡葉框架。

### 森羅烹飪指南
27 格介面：
- 書脊诗句：「循四時之序，烹森羅真味」
- 步驟→方塊對應表（森林砧板/森林醃製台/森羅爐灶/森羅調味桌）
- **森羅品質分級**（Nether Star）：「森林有五境，菜亦有五品」
  - 凋零 ×0.5（灰） — 食材枯萎失味
  - 常木 ×1.0（白） — 平凡而穩定
  - 新芽 ×1.25（綠） — 初生嫩芽般清新
  - 古木 ×1.5（青） — 深林老木稀有
  - 森羅 ×2.0（金） — 森林之心至味
- **爐灶點燃／澆滅方式**（打火石）

### 森羅廚階
27 格介面：
- 玩家頭顱：當前階數、稱號、**森羅詩句**（按階數變化）、經驗、距下一階尚需多少
- 經驗獲取說明（森羅 +50 / 古木 +40 / 新芽 +30 / 常木 +20 / 凋零 +5）

## 設計原則

- **純瀏覽介面**：GUI 內所有點擊與拖曳一律取消，玩家無法從介面取走物品——料理仍須透過「潛行右鍵方塊觸發烹飪」取得。
- **InventoryHolder 標記**：以 `GuiHolder` 辨識自身 GUI，不干擾玩家背包或第三方介面。
- **分頁純邏輯**：`GuiLayout` 為無狀態工具類，與 inventory 渲染解耦，可單元測試。
- **指令相容**：原有 `/kitchen recipe`、`/kitchen level` 等聊天指令保留不變。
- **主題沉浸**：所有文字、顏色、填充板、詩句均遵循「森羅物語」童話森林廚房調性。
